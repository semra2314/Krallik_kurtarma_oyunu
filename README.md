# Krallık - KRALLAR UYUMAZ

Basit, görselli ve müzikli bir tkinter macera uygulaması.

Kısa kullanım:

- Python 3.10+ önerilir.
- Gerekli paketleri kurmak için:

```bash
pip install -r requirements.txt
```

- (İsteğe bağlı) Arka plan müziği için proje klasörüne `bg_music.mp3` dosyasını koyun.

- Uygulamayı başlatmak için:

```bash
python game.py
```

Notlar:

- Müzik için `pygame` kullanılıyor; eğer yüklü değilse program yine çalışır fakat müzik çalmaz.
- Arayüz `tkinter` ile yapılmıştır; Windows ortamlarında Python ile birlikte gelmesi gerekir.
